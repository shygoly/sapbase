## 新增

- **采购单支持税率**：新建/编辑采购单时新增“税率(%)”字段，范围 0–100。
  PiAgent 也可以直接代填：“给这张单加 13% 税率”。
- **供应商搜索**：供应商选择从下拉改为搜索，支持按名称/编码模糊查找。

## 变化

- **审批意见展示**：审批历史中的意见改为按时间倒序，最新一条置顶。
- **导出文件名**：对账单导出文件名包含账期，避免重复覆盖。

## 修复

- 修复对账金额在四舍五入后差 0.01 的问题。
- 修复移动端表单在 iOS 上键盘遮挡“提交”按钮的问题。

## 对谁有影响

| 角色 | 影响 |
|---|---|
| 采购员 | 新建采购单可填税率；旧单默认 0 |
| 财务 | 对账报表新增税率列；历史数据不追溯 |
| 管理员 | 无权限变化 |

## 怎么用

1. 打开「采购 → 采购单 → 新建」。
2. 在“金额”下方填写“税率(%)”，不填默认 0。
3. 保存后可在详情页看到“含税金额”。

## 需要帮助

- 在页面右下角打开 PiAgent，问“税率怎么填”。
- 或提交反馈：页面右上角「反馈」→ 选择「使用问题」。
