## 1. 文档说明

### 1.1 文档用途

本文件用于向已进入进一步技术评估阶段的合作团队说明本项目定制开发范围、功能要求、必要外部依赖和技术交付条件。

### 1.2 需求范围

本次需求仅包括两项定制开发工作：一是教育内容生产与运营管理平台，二是面向内容生产和学习服务的智能体应用。既有标准能力仅作为外部依赖说明，不纳入本文件的定制开发清单。

### 1.3 披露边界

本文件不披露项目地区、项目单位、平台品牌、原始条目编号及具体合作关系，仅说明定制开发范围及技术交付条件，不承载非技术性合作条款及外部评审规则。

## 2. 项目需求总览

### 2.1 建设目标

围绕教学内容生产、课程运营、学习服务、测评反馈和教学管理，建设可供教师、学生及管理人员使用的定制化平台与智能体应用，形成从内容准备、智能生成、审核发布到学习使用、测评反馈和数据分析的业务闭环。

### 2.2 使用角色

| **角色** | **主要使用内容** |
| --- | --- |
| 教师 | 课程建设、素材管理、内容生成、审核发布、教学任务、测评和学情分析 |
| 学生 | 课程学习、章节练习、知识点测评、错题反馈、学习推荐和离线学习 |
| 教学管理人员 | 课程建设统计、教学运行分析、学情预警和专题数据查看 |
| 系统管理人员 | 用户组织、身份认证、角色权限、接口配置、日志审计和数据同步 |

### 2.3 定制开发范围

| **定开工作** | **建设内容** | **主要使用角色** | **交付形态** |
| --- | --- | --- | --- |
| 教育内容生产与运营管理平台 | 课程与知识结构、素材、内容生成、审核发布、教师工作台、数据分析、身份权限及业务数据对接 | 教师、教学管理人员、系统管理人员 | 可部署、可配置、可集成的平台功能 |
| 智能体应用 | 内容生产智能体、学习服务智能体，以及测评、推荐、离线学习、生成内容标识和人工终审能力 | 教师、学生、教学管理人员 | 可调用、可编排、可追踪的智能体应用 |

### 2.4 整体业务流程

内容准备→知识结构确认→智能生成→人工审核→正式发布→教学任务→学生学习与测评→教师终审→个性化推荐与巩固→学情分析与教学改进。

### 2.5 实施周期要求

本次定制开发的整体交付周期为90日。

### 5.2 接口与任务协同

涉及异步智能体任务时，应具备任务状态查询、回调、失败重试和唯一任务标识能力；现有系统调用本次建设能力时，应传递必要的课程、知识点、用户身份和任务上下文，并避免重复请求产生重复正式数据。

### 5.3 数据与权限

身份、功能、数据和资源权限均应在服务端校验。业务数据同步采用只读账号、最小权限和IP白名单，限内网访问，不得修改源数据，并保留同步、调用、异常和对账记录。

### 5.4 性能与容量

各项性能、容量、文件大小、并发量、响应时间、保存周期和更新频率，以第3章、第4章对应功能条目的量化及验收要求为准。

### 5.5 日志、监控与安全

应记录内容生成、发布审核、用户登录、权限变更、数据导出、配置修改、接口调用及异常处理过程，确保关键操作可查询、可审计、可追溯。
