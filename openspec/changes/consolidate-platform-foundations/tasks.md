# Implementation Tasks

## 里程碑与验收门

| 阶段 | 范围 | 验收门（命令 + 期望） |
| --- | --- | --- |
| **W0** 收敛准备 | 依赖面清点 + 存量导出 | 列出前端/后端对旧工作流的全部调用点；`workflow_*` 三表导出脚本可用（行数可核对） |
| **W1** 双跑 | 蓝图接口补齐旧前端所需的读接口 | 同一份流程定义：旧接口与新接口读出的实例/历史**一致**（对拍测试） |
| **W2** 前端切换 | `admin/workflows` 改数据源 | 页面功能不变（状态图/时间线/迁移按钮）；`tsc` + `next build` 通过 |
| **W3** 停用与删除 | 两棵旧树退场 | 旧路由返回 410 + 迁移指引；`workflows` / `workflow-context` 从 app.module 摘除后全量回归全绿 |
| **N0** Outbox | 持久化事件 + 投递器 | 业务写入与事件同事务（故障注入：业务回滚则无事件）；至少一次投递 + 幂等；投递状态可查 |
| **N1** 通知 | `notifications` 表替换内存 Map | 重启后未读通知仍在；审批待审会产生通知；已读持久 |
| **N2** 待办 | 按审批人聚合的 inbox | 「我的待办」列出所有 pending 审批；批准后从待办消失（同一事务） |
| **N3** 最小可观测 | 结构化日志 + 关键路径耗时 | 事件投递失败可定位（含重试次数与最后错误） |
| **A1** AI→蓝图转换器 | `mergedDefinition` → 五层 | 纯函数可测；缺层就缺层（不编） |
| **A2** AI 产物进既有链 | 编译 + 装载 + 交付 | AI 生成的模块能被编译成 IR、能装载、能签名交付（复用既有 e2e 形态） |

### 执行约定

1. 每完成一项：勾选 + 附证据（命令 + 结果），不写"应该可以"。
2. **协议先行**：N0 的 outbox 形状先写进协议文本再实现。
3. **不放松既有闸**：收敛只搬能力不改判据；通知/待办复用既有权限与审计。
4. fail-closed：迁移非法拒、事件与业务同事务（业务回滚则无事件）。
5. **先双跑再删**：W 阶段任何一步都要可回退；W3 之前不许删旧代码。
6. 每阶段结束跑全量回归（单元 + e2e + wasm-modules + tsc + `verify-from-zero`）。

## Phase N0: Outbox（先于通知）

- [ ] 协议文本：`docs/protocols/outbox.md`（事件形状 / 幂等键 / 投递语义 / 重试策略）
- [ ] `outbox_events` 表：`id / topic / payload / occurredAt / deliveredAt / attempts / lastError / idempotencyKey`
- [ ] 发布点：与业务写入**同事务**（迁移、审批、导入）
- [ ] 投递器：至少一次 + 订阅者幂等 + 失败重试计数
- [ ] jest：业务回滚 → 无事件；重复投递 → 订阅者只处理一次；失败可查

## Phase N1: 通知

- [ ] `notifications` 表（替换 `Map`）：`userId / organizationId / type / title / body / read / createdAt`
- [ ] 生产者：审批待审、单据状态变化、导入完成/失败（都经 outbox）
- [ ] 已读状态持久；重启不丢
- [ ] jest：重启后未读仍在；审批待审产生通知

## Phase N2: 待办（inbox）

- [ ] `GET /inbox`：按当前审批人聚合所有 pending 审批（跨单据类型）

## Phase N3: 最小可观测

## 决策记录（本变更不做，附触发条件）

| 组件 | 决策 | 触发条件 |
| --- | --- | --- |
| 报表 / 看板 | 延后，排第一 | 第一个真实客户上线 |
| 单据输出（PDF/Excel/打印） | 与报表同批（共用输出层） | 同上 |
| 出站集成（webhook/连接器） | 不做，Outbox 留投递点 | 有具体对接方 |
| 数据范围（部门/仓库级） | 不做 | 出现可信用户属性模型 |
| 可观测性栈（OTel/Prometheus） | 不做（N3 只做最小集） | 规模或排障需求上升 |
| 部署形态（Docker/K8s） | 延后 | 客户私有部署 |
| 多币种汇率 / 时区 | 不做 | 第一张跨境单据 |
| 市场 / 结算 | 不做 | 决定卖模板（商业决策） |
| 搜索 / 图 / 向量 | 不做 | 设计期 AI 真要做 |
| 移动端 / 离线 | 不做 | 仓库/车间场景被验证 |
